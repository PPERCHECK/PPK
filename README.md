# ssait — игровая мастерская

Статический многостраничный сайт без сборки и без серверных аккаунтов. Игры, редактор и сохранения работают на устройстве. При первом открытии браузер сохраняет страницы и файлы, после этого сайт умеет открываться офлайн.

## Комнаты мастерской

- **Главная** — портал по всем разделам с собственным артом.
- **Игровой зал** — Beblox, Crafting Box, Drift Box и Night Runner.
- **Pixel Studio** — пиксельный редактор 32×32, заливка, палитра, отмена и экспорт PNG.
- **Профиль** — локальный ник, аватар, рекорды, уровни опыта и значки достижений.
- **Инструменты** — таймер фокуса, локальный блокнот, генератор идей.
- **Сообщения** — локальные комнаты и сообщения; это демо без общей переписки между людьми.
- **Журнал** — заметки о новых комнатах.

Три.js хранится в `vendor/` и распространяется по лицензии MIT (см. `vendor/THREE-LICENSE.txt`). Сайт не загружает шрифты или библиотеки с внешних CDN.

## Локальный запуск

В этой папке запусти:

```sh
python -m http.server 8000
```

Открой http://localhost:8000. Сервисный worker включается на localhost и HTTPS. Его кэш может оставаться в браузере; если после обновления видна старая версия, перезагрузи страницу.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` публикует содержимое корня на каждый push в `main`. В настройках репозитория **Settings → Pages → Build and deployment → Source** должно быть выбрано **GitHub Actions**.

Для проекта `PPERCHECK/PPK` стандартный адрес: https://ppercheck.github.io/PPK/.

Чтобы подключить собственный домен:

1. В **Settings → Pages → Custom domain** введи `ssait.ru` и сохрани.
2. В REG.RU удали старые записи `A` для `@` и `www`, которые указывают на `176.57.66.212` (старый Tilda-хостинг). Для `@` оставь четыре записи `A`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. Добавь `CNAME`: имя `www`, значение `ppercheck.github.io`.
4. Сохрани MX/TXT для почты, дождись DNS-проверки и включи **Enforce HTTPS**.

## Изменение сайта

У каждой игры и приложения собственная папка с отдельным `index.html`. Чтобы добавить новую игру, создай папку, затем добавь её ссылку в `index.html`, `games/index.html` и в список офлайн-файлов `sw.js`. После push в `main` GitHub Pages опубликует обновление автоматически.
