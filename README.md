# ssait — цифровая мастерская

Многостраничный статический сайт без сборки:

- Главная — портал и переходы по отдельным разделам.
- Игры — каталог **Beblox**, **Crafting Box**, **Drift Box**.
- Beblox — небольшой 3D-город, прогулка, машина, трафик и миссия на сбор трёх сигналов.
- Crafting Box — блочный остров, добыча и размещение блоков с локальным сохранением.
- Drift Box — аркадная гонка, занос, три круга и личный рекорд.
- Мессенджер — комнаты и локальное сохранение сообщений.
- Инструменты — таймер фокуса, блокнот с автосохранением и генератор идей.
- Журнал мастерской.

## Локальный просмотр

Запусти HTTP-сервер в этой папке командой `python -m http.server 8000`, затем открой http://localhost:8000. Для 3D-игр нужен WebGL и доступ к jsDelivr, откуда загружается Three.js.

## Работа без онлайн-сервера

Таймер, заметки, игровые рекорды, блоки и сообщения сохраняются в браузере на текущем устройстве. Они не синхронизируются между браузерами и устройствами. Мессенджер пока является локальным демо: для общих переписок и аккаунтов нужно подключить Supabase, Firebase или собственный realtime backend. Ключи сервера в файлы сайта не добавлены.

## Публикация на GitHub Pages

В репозитории лежит workflow `.github/workflows/deploy.yml`: он автоматически публикует корень проекта при push в `main`.

1. Загрузить файлы проекта в корень репозитория `PPERCHECK/PPK` и отправить первый коммит в `main`.
2. В GitHub открыть **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Дождаться зелёного workflow в **Actions**. Адрес проекта будет `https://ppercheck.github.io/PPK/`.
4. В **Settings → Pages → Custom domain** указать `ssait.ru` и сохранить. В корне уже лежит `CNAME` со значением `ssait.ru`.
5. В REG.RU настроить DNS по инструкции ниже. После проверки DNS включить **Enforce HTTPS** в настройках Pages.

### DNS для REG.RU

В управлении зоной домена добавь четыре записи `A`: имя `@`, значения `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Добавь `CNAME`: имя `www`, значение `ppercheck.github.io` (если интерфейс требует точку в конце — `ppercheck.github.io.`). Удали конфликтующие записи `A` или `AAAA` для `@` и `www`, если они остались от прежнего хостинга. Не меняй NS-серверы, если управляешь DNS-зоной в REG.RU; почтовые MX/TXT записи сохрани.

Подробно: [GitHub Pages: настройка домена](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) и [REG.RU: настройка DNS в личном кабинете](https://help.reg.ru/support/dns-servery-i-nastroyka-zony/nastroyka-resursnykh-zapisey-dns/nastroyka-resursnykh-zapisey-v-lichnom-kabinete).

Новая игра добавляется в собственной папке, например `puzzle/`; затем добавь ссылку на неё в каталог игр и на главную.
